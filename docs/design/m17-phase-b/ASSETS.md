## Map material

Leaflet **1.9.4**, its existing distribution stylesheet and `@types/leaflet` **1.9.21** provide the client-only interactive map; no React wrapper, geocoder, routing service, clustering service or map SDK was added. Leaflet code is bundled locally; no runtime CDN script executes. Markers use simple numbered shapes and verified source data, never generated board positions. There is no accommodation point or polygon.

Tiles use `https://tile.openstreetmap.org/{z}/{x}/{y}.png` directly in the browser under the [OSMF tile policy](https://operations.osmfoundation.org/policies/tiles/). Visible OpenStreetMap attribution links to its copyright page, alongside a map-issue link. Ordinary browser caching applies; no bulk/prefetch/offline download or no-cache headers are added. A destination-route-only CSP permits this tile-image origin and the proxy/headers send `strict-origin-when-cross-origin`. Private/booking/integration referrer/CSP rules are preserved. The browser's User-Agent and valid Referer identify requests. No user geolocation or analytics is requested.

**Presentation refinement after the gate:** the first render placed the activation prompt beside a long destination list, leaving a large empty desktop region. The map now loads automatically after hydration and can be hidden/reopened, preserving Atlas's meaningful map presence. The server-rendered list, official links and no-script message remain independent of the map. This changes loading presentation, not the approved coordinate/image evidence or concept. Tile requests disclose the site's origin to the provider; this expected map functionality is not tracking integration. OSM service is best-effort and may block/fail without an SLA; a production hosting/provider decision still requires operational review before deployment, which is not authorized here.

The four local points are L01 viewpoint, L02 trail start, L04 tower, L05 visitor centre. Hill of Crosses remains unpinned; its photograph does not resolve the conflicting official coordinates. No town-centre pins or unverified entrance approximations fill the regional map. Full directory coverage and editorial group distinctions are available without geographic points.
