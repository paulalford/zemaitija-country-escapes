# Milestone 16 public illustrative assets

These files are **AI-generated regional interpretations**, not actual property photography. They depict no verified accommodation features. Each image has a readable adjacent disclosure in the public UI; image alt text is empty because the atmospheric interpretation is decorative and the caption supplies its purpose/limitations. The catalog name Lakeside Cabin establishes no lake access or waterfront claim.

Exact prompts, original generated PNG paths, provenance limitations and hashes are in neighboring `.webp.json` files. WebP conversion used local FFmpeg (`libwebp`, quality 88), retaining original 1536×1024 dimensions; generation originals remain in the image tool's output directory. The approved Phase A boards supplied design direction, not shipping pixels or reference photos. No third-party photograph was copied or used as an image-generation input. No license clearance, exclusive ownership or real-property identity is claimed. New plates are implementation assets subject to the user's next independent review.

The self-hosted Cormorant Garamond normal variable font uses Latin and Latin Extended WOFF2 subsets (about 70KB combined); the latter includes Lithuanian characters. Origin: [Google Fonts project](https://github.com/google/fonts/tree/main/ofl/cormorantgaramond), version 21 delivery from `fonts.gstatic.com`, with the original [SIL Open Font License](../../public/fonts/OFL-CormorantGaramond.txt) included. The delivery stylesheet was requested for weights 500 and 600; both map to the same variable subset files. Public pages request only local font URLs. No Google stylesheet or remote font is loaded in the browser. System sans remains the supporting interface face.
